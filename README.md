# Tulsa Electrology

Professional landing page for Tulsa Electrology.

## 🚀 Getting Started
1. Open `index.html` in any modern web browser.
2. For development, ensure the `assets/` directory is maintained for styles, scripts, and images.

## 📁 Directory Structure
- `index.html`: Main landing page.
- `assets/css/style.css`: Custom styles.
- `assets/js/script.js`: Interactive logic (FAQ, mobile menu).
- `assets/images/`: Optimized WebP images and icons.
